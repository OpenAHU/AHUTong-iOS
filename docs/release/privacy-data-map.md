# iOS 隐私数据用途映射

| 数据 | 功能用途 | 本机处理 | 对外发送 | 跟踪 | 保护措施 |
| --- | --- | --- | --- | --- | --- |
| 姓名、学号 | 登录身份、校园服务展示 | 会话状态；学号进入 ThisDeviceOnly Keychain | 仅直接发送到安徽大学对应业务系统 | 否 | 不写日志、不复制到剪贴板；灰度只发送 SHA-256 摘要 |
| 校园账号密码 | 首次可见 WebView 登录与前台会话自动续期 | 用户同意后保存到 ThisDeviceOnly Keychain | `one.ahu.edu.cn`、`jw.ahu.edu.cn`、必要时的 `adwmh.ahu.edu.cn` | 否 | 不发送到开发者服务器、第三方 OCR、日志、剪贴板或备份；撤回同意立即删除 |
| 校园 Cookie | 保持教务、校园卡及其他校园服务会话 | 非持久化 WebView 导出后保存到 ThisDeviceOnly Keychain | 仅按 Cookie 域和 Path 规则发回对应安徽大学业务系统 | 否 | 只接受由 HTTPS 校方页面获取的 Cookie，原生会话中统一按 Secure 处理；不记日志；撤回同意立即删除 |
| 手机号 | 失物招领发布、浴室账户查询/缴费 | 发布表单或当前支付页面内存 | 安徽大学失物招领服务；学校校园卡 HTTPS 服务 | 否 | 仅在用户主动确认时提交；支付密码不持久化 |
| 精确位置 | 本地天气 | 授权后按次读取 | 天气查询服务 | 否 | 拒绝后可用 IP/城市查询 |
| 失物招领内容 | 列表、详情、发布 | 缓存和草稿 | 校园失物招领服务 | 否 | 所有权校验；失败不提前改变 UI |
| 支付信息 | 校园卡、招行、浴室、电控、网费 | 金额与账户仅在当前页面内存；待核验记录只把功能、订单号、方式和阶段写入受文件保护且排除备份的 Application Support 原子日志；招行网页流程使用临时 Web 容器 | 学校校园卡 HTTPS 服务；PAY-04 招行受控网页主机 | 否 | Token/Cookie/六位密码、键盘材料和请求体不进入待核验日志且不写诊断；原生四条链路按 Android 兼容协议提交，只有明确结果才结束待确认状态 |
| 课表 | App、提醒、Widget、体验账户 | App Group 快照与不含学号的体验课表副本；可从 JSON 导入 | 真实账号刷新时发送到安徽大学教务系统；体验模式不对外发送 | 否 | 撤回同意可保留课表；清除缓存或重新导入可覆盖/删除 |

App 与 Widget 均内嵌 `PrivacyInfo.xcprivacy`。当前不接入广告、跨 App 跟踪或第三方崩溃上报，也不运营汇集业务数据的自有云服务；若未来策略改变，必须先更新本表、清单、用户说明和发布审核答案。
