# iOS 隐私数据用途映射

| 数据 | 功能用途 | 本机处理 | 对外发送 | 跟踪 | 保护措施 |
| --- | --- | --- | --- | --- | --- |
| 姓名、学号 | 登录身份、校园服务展示 | 会话状态；学号进入 ThisDeviceOnly Keychain | 仅直接发送到安徽大学对应业务系统 | 否 | 不写日志、不复制到剪贴板，不发送到开发者服务器 |
| 校园账号密码 | 首次可见 WebView 登录与前台会话自动续期 | 用户同意后保存到 ThisDeviceOnly Keychain | `one.ahu.edu.cn`、`jw.ahu.edu.cn`、必要时的 `adwmh.ahu.edu.cn` | 否 | 不发送到开发者服务器、第三方 OCR、日志、剪贴板或备份；撤回同意立即删除 |
| 校园 Cookie | 保持教务、校园卡及其他校园服务会话 | 非持久化 WebView 导出后保存到 ThisDeviceOnly Keychain | 仅按 Cookie 域和 Path 规则发回对应安徽大学业务系统 | 否 | 只接受由 HTTPS 校方页面获取的 Cookie，原生会话中统一按 Secure 处理；不进入自动诊断；仅用户主动选择的网络反馈可包含；撤回同意立即删除 |
| 邮箱账号、会话与 Cookie | 用户主动连接校园邮箱、在服务端过期后恢复只读查询 | 独立 ThisDeviceOnly Keychain 记录；与校园卡和教务 Cookie 隔离，退出校园账号删除 | 学校门户/WebVPN 交换 SSO；学校网易企业邮箱入口与 mail.stu.ahu.edu.cn，按主机隔离 Cookie | 否 | 隐私 v5 披露；每次请求核对当前校园身份，拒绝跨账号结果；不记录 SID、邮件地址或完整 URL，不将校园凭据发往邮箱主机 |
| 邮件、邮箱联系人与附件 | 原生列表、阅读、写信/回复/转发、草稿、联系人、附件上传/下载与移动 | 邮件/联系人/编辑内容仅内存；下载文件在受保护临时目录，退出预览/详情删除 | 用户主动读写时发往学校邮箱服务；附件分享由用户明确选择目标 | 否 | 正文以纯文本显示，不执行 HTML/脚本或自动获取跟踪图片；读取过期最多续期重试一次；发送/保存/移动不自动重放，结果不确定时明确提示先核对服务端 |
| 校园验证码图片 | 隐私 v4 同意后，首次及后续校园服务会话建立/恢复时辅助填写验证码 | App 仅在当次登录内存中处理，不落盘 | `https://openahu.org/ocr/captcha` | 否 | 请求只包含验证码图片，不附带账号、密码、Cookie、Token 或业务数据；App 不记录图片/结果；失败只提示重试，不自动打开第二登录页 |
| 手机号 | 失物招领发布、浴室账户查询/缴费 | 发布表单或当前支付页面内存 | 安徽大学失物招领服务；学校校园卡 HTTPS 服务 | 否 | 仅在用户主动确认时提交；支付密码不持久化 |
| 精确位置 | 本地天气 | 授权后按次读取 | 天气查询服务 | 否 | 拒绝后可用 IP/城市查询 |
| 相机画面、二维码 | 用户主动扫码跳转 | VisionKit 本机识别；原文只在本次路由内存中使用 | 仅把识别匹配的二维码交给用户要打开的美团/学习通；雨课堂提示微信重扫 | 否 | 不存图片或码原文，不写日志/Sentry，不自动打开未知链接；拒绝相机授权仍可使用其他工具 |
| 菜鸟身份码入口 | 用户主动打开驿站身份码 | 安大通只构造固定的公开入口 | 淘宝 App 或公开淘宝网页，不附带校园凭据 | 否 | 身份码及淘宝登录由淘宝处理，安大通不读取、缓存或上传身份码 |
| 失物招领内容 | 列表、详情、发布 | 缓存和草稿 | 校园失物招领服务 | 否 | 所有权校验；失败不提前改变 UI |
| 支付信息 | 校园卡、招行、浴室、电控、网费 | 金额与账户仅在当前页面内存；待核验记录只把功能、订单号、方式和阶段写入受文件保护且排除备份的 Application Support 原子日志；招行网页流程使用临时 Web 容器 | 学校校园卡 HTTPS 服务；PAY-04 招行受控网页主机 | 否 | Token/Cookie/六位密码、键盘材料和请求体不进入待核验日志且不写诊断；原生四条链路按 Android 兼容协议提交，只有明确结果才结束待确认状态 |
| 课表 | App、提醒、Widget、体验账户 | App Group 快照与不含学号的体验课表副本；可从 JSON 导入 | 真实账号刷新时发送到安徽大学教务系统；体验模式不对外发送 | 否 | 撤回同意可保留课表；清除缓存或重新导入可覆盖/删除 |
| 教务考勤记录及临时 JWT | 用户主动查询课程考勤、状态筛选和分页 | 记录、SSO 临时 Cookie 和 JWT 仅当前页面客户端内存，不落盘 | ADWMH、one、kqcard 三个受控学校 HTTPS 主机 | 否 | 不请求抓拍照片、不记录 Token/URL/query；不自动上传 Sentry；用户主动选择的网络反馈可包含查询结果；不提交申诉或修改记录 |
| 自定义背景照片 | 用户通过系统 PhotosPicker 选择、更换或清除背景 | Application Support 内生成最长边 2048px 的 JPEG，移除源图元数据；偏好仅保存遮罩/视差开关，测试目录隔离 | 无 | 否 | 不请求整个照片库、不上传照片；UIKit Motion Effects 只改变本地显示，不存储或上报传感器读数 |
| 必吃榜周期及校区 | 用户主动查看公开聚合榜单 | 页面内 5 分钟缓存，无用户标识 | `https://inchangejiang.cn/api/canteen/insights`，仅公开筛选参数 | 否 | 独立无 Cookie/凭据会话；不发送学号、校园 Cookie、卡号、个人账单或设备身份；不含交易上传/众包写入 |
| 快捷指令课表结果 | 用户主动查询指定日期课表、Siri 播报和快捷指令组合 | 读取账号隔离的本机快照或体验课表；不启动后台登录 | 仅在用户执行动作时向系统 Siri/快捷指令返回课程、节次、地点和数据时间；不发往开发者服务器 | 否 | 要求系统身份验证；退出账号后不读取旧账号快照；无数据与无课分别返回；清除缓存删除快照 |
| 崩溃、卡顿、性能与安装日活 | 稳定性、抽样性能、按安装统计活跃 | SDK私有缓存；随机安装ID保存在本机；运行/错误日志内存10分钟、5MiB | 当前隐私v7确认接受后发送至Sentry德国节点；Release性能10%，日活独立全采样 | 否 | 自动事件脱敏，不含业务正文；MetricKit系统原始诊断附件、Watchdog、受控breadcrumbs；无截图/回放或校园码最终失败；撤回后停止新采集并清理缓存 |
| 主动反馈/加密日志导出 | 用户主动排查问题 | 有界内存网络详情，单份正文最多256KiB；导出仅密文临时文件 | 逐次预览并选择后发至Sentry；或由用户分享加密文件 | 是（反馈附件/描述可能含个人信息） | 网络详情默认不选，可能含学号、Cookie、Token及查询结果；密码、服务写入密钥、支付/邮箱正文和二维码排除；换号清空；私钥不在App |

App 与 Widget 均内嵌 `PrivacyInfo.xcprivacy`。主 App 接入经过过滤的 Sentry 诊断；不接入广告或跨 App 跟踪，也不运营汇集校园业务数据的自有云服务。崩溃与其他诊断数据在主 App 清单中声明为不用于跨App跟踪；随机安装ID关联的诊断/性能/交互及主动反馈按实际范围声明，用于App功能及分析。采集与符号文件上传边界见 [Sentry 运维说明](../operations/sentry.md)；发布审核答案须与本表、清单和实际配置保持一致。
