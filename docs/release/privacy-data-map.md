# iOS 隐私数据用途映射

| 数据 | 功能用途 | 本机处理 | 对外发送 | 跟踪 | 保护措施 |
| --- | --- | --- | --- | --- | --- |
| 姓名、学号 | 登录身份、校园服务展示 | 会话状态；学号进入 ThisDeviceOnly Keychain | 仅直接发送到安徽大学对应业务系统 | 否 | 不写日志、不复制到剪贴板；灰度只发送 SHA-256 摘要 |
| 校园账号密码 | 首次可见 WebView 登录与前台会话自动续期 | 用户同意后保存到 ThisDeviceOnly Keychain | `one.ahu.edu.cn`、`jw.ahu.edu.cn`、必要时的 `adwmh.ahu.edu.cn` | 否 | 不发送到开发者服务器、第三方 OCR、日志、剪贴板或备份；撤回同意立即删除 |
| 校园 Cookie | 保持教务、校园卡及其他校园服务会话 | 非持久化 WebView 导出后保存到 ThisDeviceOnly Keychain | 仅按 Cookie 域和 Path 规则发回对应安徽大学业务系统 | 否 | 只接受由 HTTPS 校方页面获取的 Cookie，原生会话中统一按 Secure 处理；不记日志；撤回同意立即删除 |
| 邮箱账号、会话与 Cookie | 用户主动连接校园邮箱、在服务端过期后恢复只读查询 | 独立 ThisDeviceOnly Keychain 记录；与校园卡和教务 Cookie 隔离，退出校园账号删除 | 学校门户/WebVPN 交换 SSO；学校网易企业邮箱入口与 mail.stu.ahu.edu.cn，按主机隔离 Cookie | 否 | 隐私 v5 披露；每次请求核对当前校园身份，拒绝跨账号结果；不记录 SID、邮件地址或完整 URL，不将校园凭据发往邮箱主机 |
| 邮件、邮箱联系人与附件 | 原生列表、阅读、写信/回复/转发、草稿、联系人、附件上传/下载与移动 | 邮件/联系人/编辑内容仅内存；下载文件在受保护临时目录，退出预览/详情删除 | 用户主动读写时发往学校邮箱服务；附件分享由用户明确选择目标 | 否 | 正文以纯文本显示，不执行 HTML/脚本或自动获取跟踪图片；读取过期最多续期重试一次；发送/保存/移动不自动重放，结果不确定时明确提示先核对服务端 |
| 校园验证码图片 | 隐私 v4 同意后，首次及后续校园服务会话建立/恢复时辅助填写验证码 | App 仅在当次登录内存中处理，不落盘 | `https://openahu.org/ocr/captcha` | 否 | 请求只包含验证码图片，不附带账号、密码、Cookie、Token 或业务数据；App 不记录图片/结果；失败只提示重试，不自动打开第二登录页 |
| 手机号 | 失物招领发布、浴室账户查询/缴费 | 发布表单或当前支付页面内存 | 安徽大学失物招领服务；学校校园卡 HTTPS 服务 | 否 | 仅在用户主动确认时提交；支付密码不持久化 |
| 精确位置 | 本地天气 | 授权后按次读取 | 天气查询服务 | 否 | 拒绝后可用 IP/城市查询 |
| 失物招领内容 | 列表、详情、发布 | 缓存和草稿 | 校园失物招领服务 | 否 | 所有权校验；失败不提前改变 UI |
| 支付信息 | 校园卡、招行、浴室、电控、网费 | 金额与账户仅在当前页面内存；待核验记录只把功能、订单号、方式和阶段写入受文件保护且排除备份的 Application Support 原子日志；招行网页流程使用临时 Web 容器 | 学校校园卡 HTTPS 服务；PAY-04 招行受控网页主机 | 否 | Token/Cookie/六位密码、键盘材料和请求体不进入待核验日志且不写诊断；原生四条链路按 Android 兼容协议提交，只有明确结果才结束待确认状态 |
| 课表 | App、提醒、Widget、体验账户 | App Group 快照与不含学号的体验课表副本；可从 JSON 导入 | 真实账号刷新时发送到安徽大学教务系统；体验模式不对外发送 | 否 | 撤回同意可保留课表；清除缓存或重新导入可覆盖/删除 |
| 快捷指令课表结果 | 用户主动查询指定日期课表、Siri 播报和快捷指令组合 | 读取账号隔离的本机快照或体验课表；不启动后台登录 | 仅在用户执行动作时向系统 Siri/快捷指令返回课程、节次、地点和数据时间；不发往开发者服务器 | 否 | 要求系统身份验证；退出账号后不读取旧账号快照；无数据与无课分别返回；清除缓存删除快照 |
| 崩溃与故障诊断 | 定位兼容性、共享权限、会话续期和校园码最终失败 | SDK 使用 App 私有诊断缓存；撤回同意后停止新采集并清理缓存 | 当前隐私 v6 确认且同意后发送至 Sentry 德国节点 `ingest.de.sentry.io` | 否 | 过滤后的堆栈、App/系统版本、设备型号、固定故障分类与数字网络错误码；不发送账号、凭据、请求内容、课程、邮件或二维码。关闭日志、自动网络内容、截图、回放及追踪，服务端禁止新事件存储 IP |

App 与 Widget 均内嵌 `PrivacyInfo.xcprivacy`。主 App 接入经过过滤的 Sentry 诊断；不接入广告或跨 App 跟踪，也不运营汇集校园业务数据的自有云服务。崩溃与其他诊断数据在主 App 清单中声明为不关联身份、不用于跟踪，仅用于 App 功能。采集与符号文件上传边界见 [Sentry 运维说明](../operations/sentry.md)；发布审核答案须与本表、清单和实际配置保持一致。
