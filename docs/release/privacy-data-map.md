# iOS 隐私数据用途映射

| 数据 | 功能用途 | 本机处理 | 对外发送 | 跟踪 | 保护措施 |
| --- | --- | --- | --- | --- | --- |
| 姓名、学号 | 登录身份、校园服务展示 | 会话状态；凭据进入 ThisDeviceOnly Keychain | 安徽大学对应业务系统 | 否 | 不写日志、不复制到剪贴板；灰度只发送 SHA-256 摘要 |
| 手机号 | 失物招领发布、浴室账户查询/缴费 | 发布表单或当前支付页面内存 | 安徽大学失物招领服务；学校校园卡 HTTPS 服务 | 否 | 仅在用户主动确认时提交；支付密码不持久化 |
| 精确位置 | 本地天气 | 授权后按次读取 | 天气查询服务 | 否 | 拒绝后可用 IP/城市查询 |
| 失物招领内容 | 列表、详情、发布 | 缓存和草稿 | 校园失物招领服务 | 否 | 所有权校验；失败不提前改变 UI |
| 支付信息 | 校园卡、招行、浴室、电控、网费 | 金额与账户仅在当前页面内存；待核验记录只把功能、订单号、方式和阶段写入受文件保护且排除备份的 Application Support 原子日志；招行网页流程使用临时 Web 容器 | 学校校园卡 HTTPS 服务；PAY-04 招行受控网页主机 | 否 | Token/Cookie/六位密码、键盘材料和请求体不进入待核验日志且不写诊断；原生四条链路按 Android 兼容协议提交，只有明确结果才结束待确认状态 |
| 教学评价内容 | 教评问卷、匿名或实名提交 | 当前问卷与本机预设 | 安徽大学教务评教系统 | 否 | 每次提交需用户明确确认；登录 Token 仅内存 |
| 课表 | App、提醒、Widget | App Group 快照 | 安徽大学教务系统 | 否 | 用户退出时清理共享快照 |

App 与 Widget 均内嵌 `PrivacyInfo.xcprivacy`。当前不接入广告、跨 App 跟踪或第三方崩溃上报，也不运营汇集业务数据的自有云服务；若未来策略改变，必须先更新本表、清单、用户说明和发布审核答案。
