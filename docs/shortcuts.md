# Siri 与快捷指令

安大通提供两个 App Intents 动作，不需要单独启用 SiriKit 扩展或第三方 SDK。

## 从设置开始

打开安大通 → 设置 → Siri 与快捷指令。引导页提供两个动作的示例口令、日期选择说明和本机数据来源，并使用系统 `ShortcutsLink` 打开快捷指令。入口使用与其他设置行相同的轻触觉、高亮和短缩放反馈；减弱动态效果时保留非动态反馈。

## 打开付款码

在系统“快捷指令”中搜索安大通，添加“打开付款码”。也可以尝试对 Siri 说“打开安大通付款码”。

动作会打开 App，进入首页并展开校园卡付款码，使用现有二维码获取、刷新和登录恢复流程。重复执行会重新请求显示付款码；如果当前在首页的二级页面，也会回到首页。未登录时保留本次打开请求，完成首次设置及真实校园登录后继续；体验账户会提示先登录真实账号。

该动作要求设备通过系统身份验证。付款码只在 App 内显示，不作为快捷指令输出，不复制二维码内容或执行扣款。也支持 `ahutong://payment-code` URL。

## 查询指定日期课表

在系统“快捷指令”中添加“查询指定日期课表”，将“日期”设置成固定日期、当前日期、调整后的日期或“每次询问”。Siri 触发语句可以使用“用安大通查询课表”，随后选择或回答日期。

动作返回文字并提供 Siri 对话，后面可以连接“朗读文本”“显示结果”等系统动作。返回内容包括日期、教学周、按节次排序的课程和地点，并说明本机数据来源。

| 情况 | 返回行为 |
| --- | --- |
| 当天有课 | 返回课程列表、节次和地点 |
| 已有课表，当天没有排课 | 明确返回“当天没有课程” |
| 已成功同步的空课表 | 返回“当天没有课程” |
| 从未同步、未导入、缓存损坏或无法确定教学周 | 提示没有可用数据，先打开 App 同步或导入；不推断无课 |
| 日期早于学期第 1 周或晚于第 20 周 | 说明超出已同步学期范围，无法判断是否有课；不把周次截断为第 1/20 周 |
| 尚未完成首次设置 | 提示先打开 App 完成设置 |
| 未登录真实账号且不在体验模式 | 提示登录或使用体验账户导入课表 |
| 设备数据暂时不可读取 | 提示解锁并打开 App 后重试 |

真实账户在首页或课表页成功加载课程、并取得可靠教学周后，为当前账号保存查询快照；刷新课表后更新快照。当前周暂时不可用时仅沿用同学期已有的周次基准，不创建猜测基准。预览下学期不覆盖当前学期快照。

体验账户直接查询本机保留或导入的课表。查询无需联网，也不会在后台启动校园登录或 WebView。真实账户数据按账号隔离，退出登录后不可通过该动作读取；清除缓存也会移除查询快照。

日期采用用户所选的年月日，再按校园的 Asia/Shanghai 时区和周一开周计算，不因用户在海外而错查前一天。当前只回答本机快照覆盖的学期（第 1～20 周）；不尝试猜测其他学期的开学日期。离线结果不能反映尚未同步的临时调课，文字中始终提示本机来源，已知同步时间时会一并返回。

## 验证边界

单元测试覆盖日期/周次、空课表与缺失数据、账号隔离、退出登录、体验模式、损坏缓存、离线基准和路由请求。UI smoke 使用演示二维码验证冷启动、其他 Tab/二级页面返回和体验账户拦截。最终侧载包的中文 Siri 识别、系统“快捷指令”发现、锁屏身份验证及真实校园付款码仍需物理 iPhone 验证。
